# Text Compare PRO - KoPaper

Free online text comparison tool to find differences between text, code, and documents. Side-by-side diff with real-time highlighting.

[kopaper.com](https://kopaper.com)

## Features

- **Side-by-Side & Inline Comparison** - Switch between Split View and Unified View modes
- **Multiple Diff Granularity** - Compare by Line, Word, or Character
- **JSON & Code Formatting** - Auto-format JSON, sort lines, trim blank lines
- **100% Client-Side Privacy** - All processing happens in your browser, no data uploaded to servers
- **Export Options** - Download Git Unified Patch (.patch) files, HTML reports, or JSON metadata
- **Keyboard Shortcuts** - Alt+N (next diff), Alt+P (previous diff), Alt+S (swap panes)
- **Smart Comparison Options** - Ignore trailing spaces, case-insensitive comparison, line numbers
- **Preset Samples** - Load preset examples for quick testing

## Usage

1. Paste original text in the left pane and modified text in the right pane
2. Or drag & drop files (.txt, .json, .js, .md) directly into the fields
3. Customize comparison options (ignore whitespace, case sensitivity, etc.)
4. Review differences with synchronized scrolling
5. Export results as patch files or HTML reports

## Privacy

Your data is processed entirely in your browser. No text or file content is sent to external servers.
