# koPaper — AI Papercraft Generator

Turn any idea into printable papercraft with AI. [kopaper.com](https://kopaper.com)

An AI-powered papercraft creation platform: describe an idea in a sentence, pick a style
(cute / low poly / pixel / fantasy), and get AI-generated papercraft designs you can print
and build. Every generation is automatically staged and published to the public Gallery,
which also powers a programmatic-SEO content flywheel.

## Tech Stack

- **Framework** — [Astro 5](https://astro.build) (static-first + SSR API endpoints), `@astrojs/cloudflare`
- **Runtime** — Cloudflare Worker (`www-kopaper-com`) with Workers Static Assets
- **Image generation** — three providers with automatic fallback:
  - Workers AI `@cf/black-forest-labs/flux-1-schnell` (free, default)
  - Pollinations (free fallback)
  - OpenRouter `bytedance-seed/seedream-4.5` (paid, optional)
  - Deterministic client-side SVG net generator (cube / pyramid / prism / toy) as a final fallback
- **State** — Workers KV (`GALLERY_KV`) staging queue for gallery drafts
- **Publishing** — GitHub Git Data API bulk commit + GitHub Actions daily flush + Cloudflare Git integration auto-deploy
- **Analytics / Ads** — Google Analytics 4, AdSense

## Features

- **AI Generator** (`/`, `/tools/*`) — prompt → styled papercraft → download / print / publish
- **Gallery** (`/gallery/`) — user-generated showcase, auto-refreshed daily from the KV queue
- **Origami tutorials** (`/origami/`) — 16 step-by-step guides with SVG step figures + HowTo JSON-LD
- **Printable templates** (`/templates/`) — car / cat / dragon / house / robot papercraft sheets
- **Printables / Learn / Letter Paper** — programmatic-SEO content collections
- **Anti-abuse** — per-IP daily rate limits on generate & queue, CORS origin whitelist,
  b64/svg size guards, trademark IP blocklist, honeypot field

## Architecture: the content flywheel

```
User generates a design
  → POST /api/generate-image  (Workers AI / Pollinations / OpenRouter)
  → POST /api/publish-queue   (stages draft into GALLERY_KV)
  → GitHub Actions (daily 14:07 UTC) POST /api/publish-flush
  → one bulk Git commit (image + markdown) to main
  → Cloudflare Git integration builds & deploys → new Gallery item live
```

## Deployment & Configuration

Deployed as a Cloudflare Worker Service with Static Assets; production config lives in
`wrangler.toml` and Cloudflare dashboard secrets:

| Variable | Purpose |
| --- | --- |
| `GALLERY_KV` (binding) | KV namespace for the staging queue + rate-limit counters |
| `GITHUB_TOKEN` (secret) | GitHub token for Git Data API commits |
| `GITHUB_REPO` / `GITHUB_BRANCH` | Target repo (`owner/repo`) and branch (`main`) |
| `PUBLISH_FLUSH_KEY` (secret) | Protects `/api/publish-flush` (header `x-flush-key` or `?key=`) |
| `OPENROUTER_API_KEY` (secret) | Optional paid image provider |
| `IMAGE_PROVIDER` | Default provider override |

The GitHub Actions workflow `.github/workflows/gallery-flush.yml` calls the flush endpoint
daily; the repo secret must match `PUBLISH_FLUSH_KEY` in Cloudflare.
