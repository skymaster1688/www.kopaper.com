Frequently Asked Questions

Is my data safe and confidential?

Yes. All diff computations take place locally inside your client web browser. Zero text or file content is sent to external servers.

Can I compare formatted JSON files?

Absolutely! Click the "Format JSON" button on either editor pane to format raw JSON strings into pretty-printed structures before comparing.

What formats are supported for export?

You can export Git-compatible Unified Patch (.patch) files, downloadable HTML visual diff reports, or JSON metadata objects.

Are keyboard shortcuts available?

Yes! Press Alt+N for next diff, Alt+P for previous diff, Alt+S to swap panes, and Alt+E to open export options.
